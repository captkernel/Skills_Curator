# CUSTOMIZE — fork an external skill for this project

Use when the user wants a skill whose examples are from a stack they don't use. Lead with this whenever RECOMMEND surfaces a stack-mismatched pick (Tag rivals in signals.md). Nothing else in the ecosystem does this.

1. **Read the source SKILL.md** (local path, or):
   ```bash
   curl -sL "https://raw.githubusercontent.com/<owner>/<repo>/main/<path>/SKILL.md" -o /tmp/source-skill.md
   ```
2. **Security-scan the source** (security-patterns.md). Stop on HIGH/CRITICAL.
3. **Scan this project** (same signals as RECOMMEND) for its tag set.
4. **Parse into sections** (split on `^## `). Per section score tag overlap and pick an action: `keep` (high overlap), `keep-trim` (some overlap, drop the rest), `rewrite-stack` (overlaps a rival framework, needs rewrite), `drop-or-rewrite` (no overlap), `rewrite-frontmatter` (always for frontmatter).
5. **Write the fork** to `~/.claude/skills/<name>-for-<project>/SKILL.md`, starting with:

```markdown
---
name: <skill-id>-for-<project>
description: |
  Project-customized fork of '<skill-id>' for '<project>'.
  Tailored to: <top 5 project tags>
metadata:
  derived_from: <skill-id>
  customized_for: <project>
  customized_at: <YYYY-MM-DD>
---

# <skill-id>-for-<project>

> **Customization in progress.** This fork was generated by Skills Curator Lite.
> The agent should now rewrite each section per the plan below.

## Customization plan

| # | Section | Action | Why |
|---|---|---|---|
| 1 | (frontmatter) | rewrite-frontmatter | Update id, derive from |
| 2 | <heading>     | <action>            | <why>                  |
```

6. **Rewrite each section** per its action. `rewrite-stack` sections get examples rewritten to the project's framework (e.g. Vue to React).
